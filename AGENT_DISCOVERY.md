# VDO discovery

The canonical local entry is `vdo`. `vdo portable-doctor --format json` validates
the fixed synthetic discovery contract. `vdo route <url> --format json` plans
routing. Metadata grants no execution authority.

The HTTP API and MCP stdio interfaces remain available as separately invoked
interfaces. Browser extension files require manual setup. Native messaging
templates contain replacement placeholders rather than machine-specific paths.
Real downloads, credentials, provider connectivity and browser behavior have
independent configuration and validation.
